Agent Loop

Observe → Think → Act

EchoPet 的核心不是播放器 UI，而是一个围绕当前状态运行的音乐 Agent：观察、理解、执行，再把结果沉淀进记忆。

01

综合语音输入、当前应用、时间、键盘行为和历史听歌行为，推断用户当前工作状态。

Recommendation

把用户状态和音乐特征连接起来

EchoPet 不是纯规则，也不是把全曲库交给 AI。它先理解人，再用 embedding 召回音乐，最后结合反馈和画像精排。

用户理解

语音文本、键盘状态、上下文、用户画像。

音乐需求

中等偏低能量、节奏稳定、有支撑感、不吵、不太悲伤。

当前约束

深夜写代码，需要继续专注，避免高刺激音乐。

1

LLM 生成 retrieval_query

把人的复杂状态翻译成音乐检索语言。

2

Embedding 召回 Top20

匹配 query embedding 与歌曲描述 embedding。

3

Score 重排 Top5

0.65 语义相似 + 0.20 反馈 + 0.10 画像 - 0.05 重复。

4

AI 最终播放队列

只对少量候选做最终排序，保证稳定性和个性化。

音乐理解

本地音乐文件经过 Essentia 特征提取。

歌曲描述

只描述歌曲本身，不预设“适合写代码”之类场景。

歌曲向量

为每首歌生成 description embedding，用于语义召回。
