# EchoPet 全局前端展示方案 (UI Architecture Plan)

更新时间：2026-05-30

本方案基于当前项目的实际代码结构（`DyberPet.py` 菜单、`input_panel.py`），定义了前端在黑客松中各个界面的**具体展示内容、布局结构和视觉风格**。此文档作为 UI 开发与美术资产生成的指导蓝图。

---

## 1. 整体视觉风格基调 (Visual Tone)

- **主题**：深色模式 (Dark Mode) + Fluent Design 亚克力毛玻璃 (Acrylic)。
- **核心色彩**：
  - 背景：深灰色 (`#1C1C1E` 或 `#2D2D30`)，带有高斯模糊。
  - 强调色：随情绪状态动态变化（如专注紫、烦躁红）。
- **质感**：现代、极简、科技感与温度感并存。去游戏化，强化“智能助手”感。
- **字体**：无衬线字体 (如 Segoe UI, Roboto)，层级分明，音乐信息大号加粗。

---

## 2. 核心界面一：角色状态层 (Character Layer)

这是直接悬浮在用户桌面上的实体，是 EchoPet 的灵魂。

### 展示内容
- **角色本体**：无背景的透明 PNG/GIF，根据情绪状态切换不同动作。
- **对话气泡 (Bubble)**：显示 `assistant_reply` 或 `bubble_text`。

### 风格规范
- **角色形象**：建议为“戴耳机的拟人化小幽灵/赛博生物”，线条圆润，色彩纯净，具有陪伴感。
- **气泡风格**：半透明黑色/深灰底色，白色文字，大圆角。气泡边框可带有当前情绪状态色的微弱发光（Glow）。

### 状态映射规范
| 状态 | 动作表现 | 强调色 |
| :--- | :--- | :--- |
| **Idle (待机)** | 闭眼轻微呼吸浮动 | 蓝色 (#0A84FF) |
| **Focus (专注)** | 戴上耳机，头顶有轻微音波/敲击动作 | 紫色 (#5E5CE6) |
| **Tired (疲惫)** | 耳机挂在脖子上，半睁眼打哈欠 | 灰色 (#8E8E93) |
| **Frustrated (烦躁)** | 身体微红，头顶有混乱毛线团，动作急促 | 红色 (#FF453A) |
| **Sad (低落)** | 抱膝缩成一团，周围有暗色粒子 | 青色 (#64D2FF) |

## 3. 核心界面二：右键菜单栏 (Context Menu)

这是用户与桌宠交互的快捷控制中心，基于现有的右键菜单改造。

### 展示内容与布局
分为两部分：**顶部状态卡片区** 和 **底部功能列表区**。

1. **顶部状态卡片区 (Status Header)**
   - **布局**：一个带深色底色和圆角的微型卡片，内边距适中。
   - **内容**：
     - 左侧：桌宠当前情绪的静态小头像 (Avatar)。
     - 右侧纵向排列：
       - `[宠物状态]`：例如 "🎧 正在帮你找歌..." (文字颜色使用当前情绪色)。
       - `[播放状态]`：例如 "▶️ 正在播放"。
       - `[当前推荐]`：例如 "🎵 Midnight Rain - LoFi Dreams" (滚动截断或缩略显示)。
2. **底部功能列表区 (Menu Actions)**
   - **Open EchoPet**：主入口，图标为麦克风或对话框，字体加粗。
   - **Debug Tools (折叠项)**：收纳所有原版功能（Dashboard, 切动作等）。
   - **Exit**：退出。

### 风格规范
- Fluent 风格的圆角阴影菜单。
- 选中的 Item 有半透明的高亮背景色。
- 顶部卡片区与下方菜单项有明显的分割线或留白。

## 4. 核心界面三：主输入与响应面板 (Input & Response Panel)

这是用户进行复杂交互（录音、查看推荐详情、反馈）的主舞台（对应代码中的 `input_panel.py`）。

### 展示内容与布局
采用 **上下分层** 或 **左右分栏** 的卡片式结构。整个面板是一个带有毛玻璃背景的圆角窗口。

1. **上方区：情绪采集 (Emotion Input)**
   - **标题**：EchoPet (带有当前情绪色的小圆点装饰)。
   - **输入框**：大圆角，深底色，无明显边框的 LineEdit。提示词：“告诉 EchoPet 你现在感觉如何...”。
   - **录音控制**：一个显眼的圆形麦克风按钮。点击后变为红色呼吸灯效果，外围有声波扩散动画。提交按钮在右侧。
2. **下方区：音乐响应与推荐 (Music Recommendation)**
   - **分析状态文本**：“根据你现在的疲惫，EchoPet 为你挑选了...”
   - **音乐卡片 (Track Card)**：
     - 左侧：方形音乐封面 (Cover Art)。
     - 右侧：
       - **歌曲名** (大号，白字加粗)
       - **歌手** (中号，灰字)
       - **情绪标签 (Tags)**：如 `[lofi]` `[calm]`。标签背景为情绪颜色的 20% 透明度，文字为情绪色。
3. **底部区：交互反馈 (Feedback)**
   - 放置横向排列的反馈按钮，使用 Emoji + 简短文案：
     - `👍 懂我`
     - `👎 换一首`
     - `⚡ 更有力量`

### 风格规范
- 摒弃生硬的线条和强烈的对比块。
- 利用灰度层级（纯黑、深灰、中灰）来区分背景、输入框和音乐卡片。
- “音乐卡片”区域应当具有轻微的悬浮阴影（Elevation），使其在视觉上最靠前，作为核心交付物。
