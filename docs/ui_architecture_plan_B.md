# EchoPet 设计系统与风格指南 (方案B：Retro Lo-Fi / 像素随身听)

更新时间：2026-05-30

本方案为 EchoPet 提供了第二套设计选择。有别于方案A的“暗黑科技感”，本方案主打 **“复古随身听 (Retro Walkman)”** 与 **“Lo-Fi 像素风”**。这种风格自带浓厚的情绪张力和音乐属性，在黑客松中能够瞬间抓住评委的眼球，传递出“治愈、放松、陪伴”的产品心智。

---

## 1. 核心设计理念 (Design Philosophy)

**「Nostalgic Comfort 怀旧陪伴」**

- **Retro UI 基底**：UI 面板模拟 90 年代随身听 (Walkman) 或复古合成器 (Synthesizer) 的物理质感。按钮有实体按压感，使用大面积的米白色和暖色调。
- **像素化元素 (Pixel Art)**：桌宠角色和部分 UI 图标采用精致的高阶像素艺术 (Hi-Bit Pixel Art)，打破传统软件的冰冷感。
- **Lo-Fi 氛围色**：以低饱和度的暖色为主，配合蒸汽波 (Vaporwave) 风格的强调色，视觉上让人感到极度放松。

---

## 2. 全局色彩规范 (Color Palette)

系统采用 **复古暖色模式 (Retro Light Mode)**。

- **背景色**：复古米白 / 卡其色 `#F4F1EA`，带有轻微的纸张或塑料磨砂纹理。
- **主文本色**：深炭黑 `#2C2C2C`，复古像素字体或粗体无衬线字。
- **UI 边框与阴影**：硬阴影设计 (Hard Shadows)，如黑色 `#000000` 向右下角偏移，突出复古 UI 的立体感。
- **情绪状态色 (Lo-Fi Emotion Accents)**：
  - `Idle` (待机)：磁带绿 `#88C0D0`
  - `Focus` (专注)：合成器黄 `#EBCB8B`
  - `Tired` (疲惫)：落日橙 `#D08770`
  - `Frustrated` (烦躁)：复古红 `#BF616A`
  - `Sad` (低落)：午夜蓝 `#5E81AC`

---

## 3. 角色视觉形象 (Character Identity)

### 形象设定：像素小卡带 / 随身听小精灵 (Pixel Cassette Sprite)
- **造型**：一个有着大眼睛的像素小卡带 (Cassette Tape) 或老式随身听，头上顶着两根老式天线或戴着有线耳机。
- **质感**：精致的像素艺术 (Pixel Art)。

### 状态动画 (State Animations)
1. **Idle (待机)**：磁带齿轮缓慢转动，眼睛眨巴，音符像素在头顶飘动。
2. **Focus (专注)**：齿轮转速加快，戴上学霸眼镜，头顶冒出小火苗，专注听歌。
3. **Tired (疲惫)**：磁带稍微有些卡带（画面轻微故障闪烁 glitch 效果），眼睛变成蚊香眼 `@@`。
4. **Frustrated (烦躁)**：磁带带子被扯出来一点，小脸通红，疯狂跺脚，头顶冒出愤怒的像素符号 `#@%!`。
5. **Sad (低落)**：磁带颜色变灰暗，屏幕上出现像素雨滴，眼角挂着一滴像素眼泪。

## 4. 界面设计规范 (UI Specifications)

### 4.1 右键菜单 (Context Menu) - "复古操作面板"

- **视觉风格**：模拟老式操作系统的菜单（如 Windows 95 或早期 Mac OS），但做了现代化圆角处理。有明显的黑色描边和纯色硬阴影。
- **顶部信息面板 (Status Header)**：
  - 设计成一个迷你的“液晶显示屏” (LCD Screen)。
  - 背景为经典的黄绿色 LCD 底色 (`#9EAC88`)，文字为深色像素体。
  - 显示内容：`[宠物状态]` (如 `STATUS: SEARCHING...`) | `[播放状态]` (如 `PLAYING: LO-FI`) | `[当前推荐]`。
- **菜单项**：
  - `[ Eject / Open EchoPet ]`：作为主入口，旁边带有一个复古的弹出磁带图标。
  - `[ System Settings ]`：收纳 Debug 工具。

### 4.2 主输入与响应面板 (Input Panel) - "情绪随身听"

整个面板设计得像一个立体的复古随身听设备。

1. **上方区：情绪磁带仓 (Emotion Input)**
   - **标题**：EchoPet Walkman (复古字体)。
   - **录音按钮**：设计成随身听上经典的红色圆形 `REC` 物理按钮。点击时有按下凹陷的效果，旁边有一盏红色的 LED 录音指示灯亮起。
   - **输入框**：设计成随身听上的标签贴纸区（白底，带一点折痕），提示词：“写下你的心情...”。

2. **下方区：音乐播放器卡片 (Music Player Response)**
   - 设计成随身听的播放界面。
   - **封面**：正方形，边缘有轻微磨损或复古滤镜效果。
   - **信息区**：滚动显示的 LCD 字体歌曲名和歌手。
   - **情绪标签 (Tags)**：像随身听上的物理拨动开关或彩色标签贴纸，颜色取自“情绪状态色”。

3. **底部区：机械反馈按钮 (Mechanical Feedback)**
   - 像收音机下方的一排方形物理按键。
   - `[ KEEP ]` (懂我/继续)
   - `[ SKIP ]` (切歌)
   - `[ BOOST ]` (更有力量)
