# EchoPet 设计系统与风格指南 (Hackathon Edition)

更新时间：2026-05-30

为了在黑客松中脱颖而出，EchoPet 需要一套高度统一、具有极强视觉冲击力且符合其“情绪陪伴”定位的设计语言。本指南定义了 EchoPet 的全局设计规范，覆盖角色形象、右键菜单、以及核心的输入与状态面板。

---

## 1. 核心设计理念 (Design Philosophy)

**「Cyber-Warmth 赛博温度」**

EchoPet 不是一个冷冰冰的效率工具，也不是一个纯粹的播放器。它是“懂你此刻状态的伙伴”。
- **Fluent Design 基底**：基于 `PySide6-Fluent-Widgets`，大量使用亚克力（Acrylic）毛玻璃效果、大圆角、流畅动画，完美融入现代桌面环境。
- **情绪化色彩 (Emotional Color)**：UI 的点缀色和角色的状态光效会随着当前情绪分析结果而改变。
- **极简且聚焦**：去除原版桌宠繁杂的“养成”元素，视觉中心永远在“你的情绪”和“它的回应（音乐）”上。

---

## 2. 全局色彩规范 (Color Palette)

系统默认采用 **暗色模式 (Dark Mode)**，最契合程序员/学生深夜工作学习的场景，也能让音乐推荐的卡片和角色的光效更加突出。

- **背景色**：深灰亚克力 `#1C1C1E` (透明度 80%)，带背景模糊。
- **主文本色**：纯白 `#FFFFFF` (85% 不透明度)，副文本色深灰 `#EBEBF5` (60% 不透明度)。
- **情绪状态色 (Emotion Accents)**：
  - `Idle` (待机)：平静蓝 `#0A84FF`
  - `Focus` (专注)：心流紫 `#5E5CE6`
  - `Tired` (疲惫)：暗夜灰 `#8E8E93`
  - `Frustrated` (烦躁)：警示红 `#FF453A`
  - `Sad` (低落)：忧郁青 `#64D2FF`

---

## 3. 角色视觉形象统一性 (Character Identity)

原版 `DyberPet` 允许任意角色，但为了黑客松的 Demo 质感，必须提供一个**官方默认形象**。

### 形象设定建议：音乐小幽灵 / 戴耳机的像素生物
- **造型**：线条圆润，无强烈的攻击性（建议 2D 平滑矢量风或精致的高阶像素风）。
- **核心道具**：**耳机**。耳机是它“听你说话”和“放音乐”的视觉锚点。

### 状态动画 (State Animations)
桌宠的动作必须与 `/api/analyze` 返回的 `current_state` 强绑定，且变化要足够明显：
1. **Idle (待机)**：闭眼轻轻随呼吸上下浮动，耳机线微微摇摆。
2. **Focus (专注)**：睁开眼，戴上耳机，头顶出现轻微的“音波”或“加载”符号，敲击键盘。
3. **Tired (疲惫)**：耳机滑落到脖子上，眼睛变成半睁的豆豆眼，偶尔打哈欠或冒出“Zzz”气泡。
4. **Frustrated (烦躁)**：身体变成微红色，头顶出现混乱的毛线团（💢），动作急促。
5. **Sad (低落)**：抱膝缩成一团，颜色变暗变冷，周围有小雨滴的粒子效果。

## 4. 界面设计规范 (UI Specifications)

### 4.1 右键菜单 (Context Menu)

右键菜单是用户与桌宠交互的“快捷入口”，需要剥离冗杂，提供清晰的情绪反馈。

- **视觉风格**：Fluent 圆角菜单，亚克力背景。
- **顶部信息面板 (Status Header)**：
  - 不再是简单的文字，而是**微型卡片**。
  - 左侧：桌宠的小头像（跟随状态切换表情）。
  - 右侧排版：
    - `[宠物状态]` (例如：🎧 正在帮你找歌...) -> 使用对应的**情绪状态色**高亮。
    - `[播放状态]` (例如：▶️ 正在播放) 
    - `[当前推荐]` (例如：🎵 Midnight Rain - LoFi Dreams)
- **菜单项**：
  - 采用清晰的 Fluent Icons (如 `Mic` 图标对应打开面板)。
  - `Open EchoPet` 作为第一主按钮，字体加粗或增加微背景色。
  - 原版功能折叠进 `Debug Tools`，使用次级灰色。

### 4.2 输入与状态面板 (EchoPet Input Panel)

这是黑客松演示的**核心高光舞台**，需要将其设计为“音乐推荐卡片”与“对话气泡”的结合体。

#### 布局结构：上下/左右分栏结构
采用 `CardWidget` 承载，整体是一个悬浮的圆角卡片。

**Top/Left 区：情绪输入区 (Emotion Input)**
- **录音按钮**：做成大号的圆形按钮，正常状态为强调色。点击录音时，按钮变为**红色呼吸态**，外圈有波纹扩散动画（视觉表现“正在倾听”）。
- **文本框**：无边框或极简边框的输入框 (LineEdit)，提示词：“告诉 EchoPet 你现在感觉怎么样...”。

**Bottom/Right 区：音乐响应区 (Music Response)**
这是体现 Agent “懂你”的核心区域。
- **状态提示语**：例如“根据你的疲惫状态，为你推荐：”
- **音乐推荐卡片 (Track Card)**：
  - 左侧：专辑封面 Placeholder（正方形圆角）。如果没图可以用流光渐变色块代替。
  - 右侧：
    - **歌曲名** (大字号，加粗)
    - **歌手名** (中字号，灰色)
    - **Tag 标签**：如 `[lofi]` `[calm]` (使用 Fluent 的 `Pill` 或 `Tag` 样式，背景色取**情绪状态色**的 20% 透明度)。
- **控制与反馈区**：
  - 反馈按钮不应该是干瘪的文字，而是 Emoji + 情感化文案组合，使用 `ToolButton`：
    - 👍 `懂我`
    - 👎 `切歌`
    - ⚡ `要更有力量`

## 5. 黑客松 Demo 演示加分项 (Hackathon Wow-Factors)

为了让评委一眼记住，建议在前端实现以下细节：

1. **录音波纹反馈**：录音时，不仅按钮闪烁，桌宠头上也可以弹出一个“麦克风”的小气泡，表示正在采集。
2. **渐变色过渡**：当分析结果返回，状态从 `Frustrated` 变为 `Focus` 时，UI 面板的强调色（包括按钮边框、Tag 背景）进行一次平滑的颜色渐变过渡。
3. **沉浸式气泡**：气泡不要用直角生硬的白框。使用半透明的毛玻璃气泡，文字打字机（Typewriter）效果逐字出现，增加“思考后回复”的拟人感。
4. **状态流转的顺滑感**：
   - 菜单顶部的文字变化要有淡入淡出。
   - “正在帮你找歌...” 时，音乐推荐卡片呈现骨架屏（Skeleton Loading）闪烁效果，等接口返回后再显示真实的歌曲信息。

## 6. 落地执行建议

基于目前 `PySide6-Fluent-Widgets` 的架构，落地此设计的步骤：
1. **重构 input_panel.py**：引入 `CardWidget`、`AvatarWidget`、`PrimaryPushButton`，把现在的线性垂直布局改为卡片式分区布局。
2. **重构 DyberPet.py 菜单**：将顶部的普通 `QLabel` 包装进一个自定义的 `QWidget`，加上背景色和圆角，作为 Status Header。
3. **补充美术资产**：在 `res/` 目录下准备 5 个状态对应的标准角色 GIF，以及配套的背景虚化图。

遵循这套设计系统，EchoPet 将不再是一个“套壳的桌宠”，而是一个具有独立产品灵魂的桌面智能体。
